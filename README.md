# 내 멋진 모듈: 그리기 설명

Foundry VTT의 그리기(Drawing) 오브젝트에 마우스를 올리면 원하는 설명을 표시해 주는 모듈입니다.

TRPG 지도에서 특정 장소나 사물에 관한 정보를 보여줄 때 사용할 수 있습니다.

## 주요 기능

- 그리기 도형에 마우스를 올리면 설명 표시
- 마크다운 서식 지원
- 설명 표시 지연 시간 설정
- 직선 다각형의 실제 내부 영역 판정
- 숨겨진 도형의 설명 표시 차단
- GM이 그리기 설정 창에서 설명을 직접 편집
- 필요에 따라 스크립트 매크로 사용 가능

## 지원 환경

- 대상 버전: Foundry VTT v13 이상
- 실제 GitHub 배포 및 기본 호버 설명 기능 테스트 완료
- v14 이상의 기능 호환성은 별도로 검증되지 않았습니다.

## 현재 버전

**v1.4.0**

GitHub Release를 통해 배포하며 Manifest URL을 이용해 설치할 수 있습니다.

## 설치 (권장: Manifest URL)

이 모듈은 Foundry VTT v13 이상을 대상으로 합니다.
v14 이상의 실제 호환성은 아직 검증되지 않았습니다.

### 간편 설치 방법

1. Foundry VTT를 실행하고 Setup 화면으로 이동합니다.
2. **Add-on Modules(애드온 모듈)** 탭을 엽니다.
3. **Install Module(모듈 설치)** 버튼을 클릭합니다.
4. 아래 Manifest URL을 입력합니다.

`https://raw.githubusercontent.com/Trainrobbery/my-fvtt-module/main/module.json`

5. **Install(설치)** 버튼을 눌러 설치합니다.
6. 게임 월드에 GM으로 접속합니다.
7. **설정 → 모듈 관리(Manage Modules)** 에서
   **내 멋진 모듈: 그리기 설명**을 활성화합니다.
8. 모듈 설정을 저장하고 필요한 경우 새로고침합니다.

이 모듈은 아직 Foundry 공식 모듈 목록에 등록되지 않았습니다.
따라서 모듈 이름으로 검색하는 대신 위 주소로 설치해 주세요.

### 최신 배포 파일

[GitHub Releases에서 확인하기](https://github.com/Trainrobbery/my-fvtt-module/releases)

## 수동 설치 (대체 방법)

1. Foundry가 실행되는 컴퓨터의 실제 사용자 데이터 폴더를 확인합니다.
2. 그 안의 `Data/modules/my-module/` 폴더를 만들고 ZIP 내용물을 **그 안에 직접** 풉니다.
   이번 ZIP에는 상위 my-module 폴더가 없습니다. 파일과 vendor 폴더를 모두 복사하세요.
   이미 설치했다면 해당 폴더 바로 아래의 같은 이름 파일들을 덮어씁니다.
3. `Data/modules/my-module/module.json` 위치를 확인하고 Foundry 서버를 완전히 재시작합니다.
4. 월드 설정의 모듈 관리에서 `내 멋진 모듈: 그리기 설명`을 활성화합니다.
5. 접속한 GM과 플레이어의 화면을 새로고침합니다.

올바른 위치: `Data/modules/my-module/module.json`

잘못된 위치: `Data/modules/my-module/my-module/module.json`

폴더명은 module.json의 id와 동일한 `my-module`이어야 합니다.
ZIP을 modules 폴더에 넣기만 하거나, 압축 속 파일을 modules 바로 아래에 풀면 안 됩니다.
다른 컴퓨터에서 서버를 실행한다면 그 서버의 사용자 데이터 폴더에 설치해야 합니다.
서버 재시작은 브라우저 새로고침이나 월드 재입장과 다릅니다.

## 목록에 보이지 않을 때


- 이 모듈은 아직 Foundry 공식 모듈 목록에 등록되지 않았으므로 검색 결과에는 나타나지 않습니다. 모듈 설치 화면의 **Manifest URL** 입력란에 위 설치 주소를 입력하여 설치하세요. 설치 후 Add-on Modules 목록과 게임 월드의 모듈 관리 화면에서 확인할 수 있습니다.
- 모듈 관리의 검색어와 활성/비활성 필터를 해제하고 제목 '내 멋진 모듈: 그리기 설명'을 찾습니다.
- FVTT v11/v12에서는 최소 버전 13 조건에 걸립니다. 이 파일은 해당 버전의 호환성을 제공하지 않습니다.
- v13에서 maximum: 13은 정상 설정이었습니다. v13을 쓰고 있다면 경로와 재시작을 먼저 확인하세요.
- module.json은 필수 파일이며 module.json.txt로 저장되어 있으면 인식되지 않습니다.
- 현재 `module.json`에는 GitHub 배포용 `manifest` 및 `download` 주소가 설정되어 있습니다. Manifest URL을 이용한 자동 설치가 가능하며, 설치에 실패할 경우 GitHub Releases에서 ZIP 파일을 내려받아 수동으로 설치할 수도 있습니다.


여전히 보이지 않으면 월드에 접속한 상태에서 브라우저 개발자 도구(F12) 콘솔에 다음 코드를
실행해 인식 여부와 버전을 확인할 수 있습니다. 읽기만 하며 설정을 변경하지 않습니다.

```js
(() => {
  const m = game.modules.get("my-module");
  console.table({
    foundryVersion: game.version,
    moduleDetected: !!m,
    moduleVersion: m?.version ?? "없음",
    moduleActive: m?.active ?? false
  });
})();
```

moduleDetected가 false이면 서버 시작 로그의 module.json 관련 오류, 실제 설치 경로,
Foundry 버전이 필요합니다. true이면 설치는 인식됐으므로 목록 필터와 호환성 경고를 확인합니다.

## 기능별 사용법 및 예제

### v1.4.0: 다각형 내부 판정

다각형은 저장된 꼭짓점을 잇는 실제 영역 안에서만 설명이 표시됩니다.
경계 사각형 안에 있어도 다각형의 오목한 빈 공간이면 표시하지 않습니다.
회전한 도형도 같은 기준으로 검사하며, 변 위의 점은 내부로 취급합니다.
내부에서 빈 공간으로 이동하면 진행 중인 대기와 표시를 취소합니다.
이미 저장한 설명에는 수정 없이 적용됩니다. `geometry.mjs`도 함께 설치하세요.

첨부 씬의 다각형은 모두 직선이므로 이 방식으로 판정합니다.
곡선 보간을 사용하는 자유 그리기는 꼭짓점을 직선으로 연결해 근사하므로 곡선 경계와
차이가 있을 수 있습니다. 두 점으로 된 선은 선 두께 안에서만 반응합니다.

### v1.3.0: 마크다운 설명

기존 '호버 설명' 입력란에 마크다운을 입력하고 저장하면 툴팁에 서식이 적용됩니다.
설명은 원래 마크다운 문자열로 저장되므로 다시 설정창을 열어 수정할 수 있습니다.
기존 지연 시간과 숨김 처리 규칙은 동일합니다. 일반 줄바꿈도 그대로 표시합니다.

```markdown
## 낡은 제단
**차가운 기운**이 느껴집니다.
바닥에는 *오래된 문양*이 남아 있습니다.

- 높이: **20ft**
- 표면: ~~깨끗함~~ 균열이 많음

> 가까이 가면 속삭임이 들립니다.

`조사 DC 15`
```

제목, 굵게, 기울임, 취소선, 목록(중첩·번호·체크 포함), 인용, 인라인 코드,
코드 블록, 구분선, 표, 링크 서식을 지원합니다. 툴팁은 클릭을 받지 않으므로
링크는 표시용입니다. 이미지는 대체 텍스트로 표시합니다.
HTML 태그는 글자로 표시하며 JavaScript/data 링크는 링크로 만들지 않습니다.
Foundry의 @UUID 연결, 주사위 굴림, 수식 렌더링은 추가하지 않았습니다.

변환기는 Marked 17.0.5를 모듈 내부에 포함했습니다(MIT 라이선스).
`markdown.mjs`, `vendor/marked.mjs`, `vendor/marked-LICENSE.md`도 함께 설치해야 합니다.

### v1.2.1: 숨김 도형의 설명 차단

숨김 처리된 그리기는 GM과 플레이어 모두에게 호버 설명을 표시하지 않습니다.
대기 중 또는 표시 중 숨겨도 다음 상태 확인 시 취소됩니다(확인 주기 150ms).
다시 표시 상태로 바꾸면 설정된 지연 시간 후 설명이 나타납니다.

### v1.2.0: 표시 지연 설정

GM이 **게임 설정 → 설정 구성 → 내 멋진 모듈: 그리기 설명**에서
**호버 설명 표시 지연 (밀리초)** 값을 지정하고 저장합니다.

- 기본값: 500ms (0.5초)
- 설정 범위: 0~5000ms, 100ms 간격. 0이면 즉시 표시합니다.
- 월드 공통 설정이므로 모든 접속자에게 적용됩니다.
- 같은 도형 안에서 움직여도 대기 시간이 계속 흐릅니다.
- 다른 도형으로 이동하면 새로 기다립니다.
- 영역 이탈, 드래그 시작, 휠 조작, 창 전환, 씬 전환 시 대기를 취소합니다.
- 설정을 바꾸면 재접속 없이 반영하며, 진행 중인 대기는 새 값으로 시작합니다.

이번 변경은 표시 지연 추가이며, 이전 설치 문제에 대한 추가 수정은 하지 않았습니다.

### v1.1.0: 설정창에서 직접 입력 (권장)

1. 그리기 도구에서 도형의 설정창을 엽니다.
2. 텍스트 탭의 기존 **텍스트** 칸 아래에 추가된 **호버 설명**에 내용을 입력합니다.
3. 설정창의 기존 저장 버튼을 누릅니다.
4. 도형에 마우스를 올리면 설명이 표시됩니다. 토큰 도구에서도 사용할 수 있습니다.
5. 설명을 지우고 저장하면 툴팁이 사라집니다.

별도의 매크로는 필요하지 않습니다. 설명은 `flags.my-module.tooltip.body`에
저장되며 기존 텍스트와 다른 모듈의 설정은 유지됩니다.
이전 예제 매크로로 등록한 본문도 입력란에 나타납니다.
이전 매크로의 제목 및 GM 전용 설정은 유지됩니다.
그리기 설정창을 수정할 권한이 있는 사용자만 설명을 수정할 수 있습니다.

GitHub Manifest URL로 설치한 경우, 새 버전이 배포되면 FVTT의 **Setup → Add-on Modules** 화면에서 해당 모듈의 **Update** 버튼을 눌러 업데이트할 수 있습니다.

업데이트가 정상적으로 인식되려면 새 버전의 `module.json`과 GitHub Release ZIP 파일이 배포되어 있어야 합니다.

수동 설치한 경우에는 새로운 ZIP 파일의 내용을 기존 `Data/modules/my-module/` 폴더에 덮어쓴 뒤 Foundry 서버를 재시작하고 접속자 화면을 새로고침하세요.

### 선택 사항: 예제 매크로

씬을 가져와서 연 다음, GM 계정에서 새 매크로를 만듭니다.
매크로 유형은 **스크립트(Script)** 로 설정하고 다음 내용을 실행합니다.

```js
await game.modules.get("my-module").api.installSceneExample();
```

`+20ft` 도형에 예제 설명이 저장됩니다. 토큰 도구로 돌아가 해당 영역에
마우스를 올리면 설명이 뜹니다. 가져오기 과정에서 Drawing ID가 변경됐다면
아래의 직접 등록 방법을 사용하세요. 이 매크로를 다시 실행하면 해당 도형의
기존 my-module 설명이 예제 문구로 덮어써집니다.

## 임의의 도형에 설명 등록

GM이 그리기 도구에서 도형 하나를 선택하고 아래 스크립트 매크로를 실행합니다.
등록 후에는 토큰 도구를 사용해도 설명이 표시됩니다.

```js
await game.modules.get("my-module").api.setSelected(
  "낡은 제단",
  "표면에 오래된 문양이 새겨져 있습니다.\n차가운 기운이 느껴집니다.",
  false
);
```

마지막 값을 true로 바꾸면 UI에서 GM에게만 표시합니다.
이 설정은 비밀 데이터 보호 기능이 아닙니다. 설명은 공유 씬의 Drawing flags에
저장되므로 비밀 내용은 넣지 마세요. 다시 등록하면 설명이 교체됩니다.

선택한 도형의 설명 삭제:

```js
await game.modules.get("my-module").api.clearSelected();
```

## 예제의 범위

- 설명이 등록된 도형만 반응하며, 변경은 Foundry 문서 API로 저장됩니다.
- 직선 다각형은 꼭짓점 기반 내부 판정, 두 점짜리 선은 선 두께 기반 판정을 사용합니다.
- 다른 도형 종류는 기존의 경계 사각형 판정을 유지합니다.
- 겹치면 더 작은 경계 사각형이 우선입니다.
- 숨겨진 도형의 설명은 GM과 플레이어 모두에게 표시하지 않습니다.
- GM 전용 설명은 플레이어 UI에서 제외합니다.
- tokenVision 씬에서 플레이어는 포인터 지점의 현재 시야를 검사합니다.
- Levels 층별 판정, 저널 연결, 모바일 터치는 지원하지 않습니다.
- 마크다운 서식을 표시하고 직접 입력한 HTML은 글자로 표시합니다. 짧은 설명에 적합합니다.
- 호버 표시는 각 접속자의 브라우저에서 실행되며 GM 매크로는 등록에만 필요합니다.

## 간단한 확인

등록한 도형 안/밖으로 포인터를 움직여 표시와 해제를 확인합니다.
토큰 도구에서 확대·축소 후에도 확인하고 플레이어 계정에서 시야 밖 영역이
표시되지 않는지 확인합니다. 씬을 바꿨다가 돌아와 설명이 유지되는지도 확인합니다.
